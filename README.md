# Пульт охраны банка

Проект подключается к базе данных пропусков банка и позволяет получать информацию о карточках доступа сотрудников. Работа с базой данных осуществляется через Django ORM.

## Как установить

Для работы проекта нужно создать файл `.env` в корне проекта и указать в нём следующие переменные:

`DB_SECRET_KEY` — секретный ключ Django, используется для подписи сессий и cookies
`DB_PASSWORD` — пароль от базы данных PostgreSQL

Пример содержимого файла `.env`:

DB_SECRET_KEY=ваш_секретный_ключ
DB_PASSWORD=ваш_пароль_от_базы

**Важно:** файл `.env` не должен попадать в Git, поэтому добавьте его в `.gitignore`.

Python3 должен быть уже установлен. Затем используйте pip (или pip3, есть конфликт с Python2) для установки зависимостей:

pip install -r requirements.txt

### Запуск

python django_orm_watching_storage/main.py
